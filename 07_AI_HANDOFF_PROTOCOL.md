# AI Handoff Protocol

This file exists so future ChatGPT/AI sessions do not accidentally revive old ideas or overwrite the wrong website version.

## Before making any website change
1. Read `00_MASTER_BRAIN.md`.
2. Read `03_DECISIONS_REGISTER.md`.
3. Read `06_TASKS_AND_ROADMAP.md`.
4. Identify the exact website branch named in the current task.
5. Check whether the requested change is a brand decision or a branch-specific implementation change.

## Precedence rules
- A newer explicit user instruction overrides an older note.
- Brand vision applies across versions unless explicitly changed.
- Branch-specific layout/motion experiments do not become global rules automatically.
- Do not merge branches unless explicitly instructed.
- Do not invent prices, destinations, services, availability or legal promises.

## Current branch warning
At the time of this consolidation, the next approved website task targets **`main` only**. Do not use `replacement-v2-weekend-experiences` as the base for that task.

## Change discipline
For narrow tasks, keep changes narrow. If asked to update portrait and colours, do not quietly redesign navigation, rewrite services, change event strategy or merge experimental features.

## Brain updates
After a significant approved decision:
- update the relevant Brain file;
- update the decisions register if necessary;
- update the task list;
- archive the superseded direction if there is one.

The Brain is the strategic source of truth. The website repo is the implementation source of truth.
