# Travel By Grace — Project Brain

This repository is the long-term source of truth for the Travel By Grace brand, website direction, business decisions, operating assumptions, content strategy and active roadmap.

It is intentionally separate from the deployable website repository (`aiadopt50-zar/travel-by-grace-website`). The website repo contains code; this repo explains **why the website and business should work the way they do**.

## Read this first

1. `00_MASTER_BRAIN.md` — current source of truth and operating summary.
2. `01_BRAND_AND_VISION.md` — brand promise, audience, tone and visual direction.
3. `02_WEBSITE_CURRENT_STATE.md` — website branches, deployment state and change-control rules.
4. `03_DECISIONS_REGISTER.md` — current decisions and what has been superseded.
5. `04_CONTENT_AND_EXPERIENCES.md` — weekend-trip, event and itinerary strategy.
6. `05_OPERATIONS_AND_BOOKING.md` — services, enquiries, payments and booking assumptions.
7. `06_TASKS_AND_ROADMAP.md` — active backlog and next actions.
8. `07_AI_HANDOFF_PROTOCOL.md` — instructions for future ChatGPT/AI work so old ideas do not overwrite current decisions.
9. `08_ASSETS_AND_MEDIA.md` — known photo/vehicle/portrait and media guidance.
10. `archive/SUPERSEDED_IDEAS.md` — ideas retained for history but no longer treated as current direction.

## Core rule

The brand vision is persistent across every website version, while **website design decisions are branch/version specific**. Never assume an experiment on a replacement branch should automatically be copied into `main`.
