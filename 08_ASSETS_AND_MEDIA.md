# Assets and Media

## Portrait
Lucille's portrait is a key trust asset and should be treated as a real-person identity asset, not generic decoration.

Guidance:
- Prefer the user's supplied portrait.
- Improve brightness, contrast and crop carefully where useful.
- Avoid changing facial features or creating an uncanny, over-smoothed result.
- Test the portrait against the purple/accent palette so skin tones remain natural.

## Vehicle
Use supplied real vehicle photography where possible.

Guidance:
- Present comfort, cleanliness, practicality and luggage usefulness.
- Avoid over-emphasising model year/model naming unless strategically useful.
- Vehicle visuals can support a sense of road-trip excitement without making the brand look like a vehicle-rental company.

## Destination / trip photography
Prefer authentic supplied photos and credible destination imagery over generic stock.

Useful categories:
- Garden Route coastline
- George / airport / transport context
- Cape Town travel
- Accommodation atmosphere
- Entertainment / theatre / event context
- Road-trip lifestyle

## Social sharing
The website replacement experiment includes an Open Graph share-card concept. Social-share imagery should communicate the brand quickly on WhatsApp/Facebook and remain consistent with the current purple-led visual identity when refreshed.

## Asset hygiene
- Keep original photos safely preserved.
- Use clearly named web-optimised derivatives rather than overwriting originals when possible.
- Record which portrait is the approved current portrait before changing the production website.
